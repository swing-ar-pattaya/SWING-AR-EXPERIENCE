SWING AR EXPERIENCE V5 — วิธีอัปโหลด

1. แตกไฟล์ ZIP
2. ไปที่ GitHub repository swing-ar-pattaya/SWING-AR-EXPERIENCE
3. กด Add file > Upload files แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไม่ใช่โฟลเดอร์) ไปวาง
4. กด Commit changes และรอสักครู่
5. เปิด https://swing-ar-pattaya.github.io/SWING-AR-EXPERIENCE/?v=5 แล้วกด Ctrl+F5 หากยังเห็นหน้าเก่า
