SWING Pattaya AR Experience — ชุดไฟล์สำหรับอัปโหลดครั้งเดียว

1. เปิด repository SWING-AR-EXPERIENCE ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดจาก ZIP ไปยังโฟลเดอร์หลักของ repository และยืนยันการแทนที่ไฟล์ชื่อซ้ำ
3. รอ GitHub Pages เผยแพร่ แล้วเปิดเว็บด้วยการรีเฟรชแบบไม่ใช้แคช
4. ทดสอบ QR ทั้ง 4 จุด, ภาษา, เสียง และ AR บนมือถือจริง

ข้อจำกัด: ภาพถ่ายจริง real-step1-01.jpg ถึง real-step4-02.jpg ไม่ได้อยู่ในไฟล์ที่ได้รับ หากไม่มีบนเว็บไซต์ จะแสดงภาพประกอบจาก step-1.webp ถึง step-4.webp แทน
เสียงอ่านออกเสียงอาศัยเสียง TTS ของเครื่อง; เขมรและพม่าอาจไม่รองรับในบางอุปกรณ์
คำแปลทางการแพทย์ควรผ่านการตรวจทานโดยเจ้าของภาษาก่อนใช้งานกับผู้รับบริการจริง
