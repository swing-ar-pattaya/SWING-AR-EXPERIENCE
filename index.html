โมเดล GLB ที่ได้รับยังไม่มี Animation โบกมือ ดังนั้นเวอร์ชันนี้แสดงโมเดล 3D แบบนิ่งก่อน และจะเพิ่มการเคลื่อนไหวเมื่อมีไฟล์ GLB ที่มี Animation แล้ว การรองรับ AR ขึ้นอยู่กับอุปกรณ์และเบราว์เซอร์

🗺️ 4 ขั้นตอนการรับบริการ

เลือกขั้นตอนเพื่ออ่านรายละเอียด หรือเปิดจาก QR Code ที่แต่ละจุดบริการ

📍 ลิงก์สำหรับ QR Code แยกตามจุด

สร้าง QR Code จากลิงก์แต่ละรายการด้านล่างได้เลย แต่ละลิงก์จะเปิดเว็บไซต์และเลือกขั้นตอนนั้นให้อัตโนมัติ

หากเคยสร้าง QR Code จากลิงก์หน้าแรกอย่างเดียว จะยังไม่แยกขั้นตอน ต้องสร้าง QR Code ใหม่จากลิงก์เฉพาะจุดด้านล่าง

💗 ความรู้สุขภาพทางเพศ

HIV: ตรวจเพื่อทราบสถานะ และรับคำแนะนำเรื่องระยะเวลาที่เหมาะสมในการตรวจจากเจ้าหน้าที่

PrEP: ยาป้องกัน HIV ก่อนการสัมผัสเชื้อสำหรับผู้ที่มีข้อบ่งชี้ ต้องรับการประเมินจากบุคลากรสุขภาพ

PEP: ยาป้องกัน HIV หลังมีความเสี่ยง ควรเริ่มโดยเร็วที่สุดและไม่เกิน 72 ชั่วโมงหลังสัมผัส

STI: โรคติดต่อทางเพศสัมพันธ์บางชนิดไม่มีอาการ การตรวจและรับการรักษาอย่างเหมาะสมช่วยดูแลสุขภาพได้

ข้อมูลนี้เป็นสื่อให้ความรู้ทั่วไป ไม่ใช้แทนการประเมินทางการแพทย์
